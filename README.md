# SAAE_PAINEL
PAINEL DE CONTROLE DE BOMBAS
Sistema 64bits.
Sistema deve ser colocado no C:\SAAE_PAINEL


Requisitos:
- Windows 10 ou 11 x64, atualizado e com cURL, PowerShell e tar disponíveis.
- Acesso à internet.
- Permissão para instalar programas.
- Credenciais MQTT válidas.
- Repositório completo, incluindo runtime/php.rar e icone.ico.

Link de dependencias:
https://github.com/samuelrochacarvalho/SAAE_PAINEL/releases/tag/dependencias-v1.0
Download é efetuado automaticamente pelo instalar.bat, porem para download mais rapido indicado fazer download manual pelo navegador de preferencia.
